# Confidential Transfers — Phase 1: ElGamal Key Management — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an ElGamal key management screen for each account, gated behind an Advanced settings toggle, using the BSGS-capable `@xrplf/mpt-crypto` library from GitHub main.

**Architecture:** The ElGamal key pair (per r-address) is stored in the existing AES-256-GCM encrypted vault alongside keyrings. A new `state.elgamalKeys` map holds keys in memory while the wallet is unlocked. The UI adds a ⛨ icon to the account card that navigates to a new `view-confidential-key` screen, which handles generation, display, and password-gated private key reveal.

**Tech Stack:** Webpack 5 (target: web), `@xrplf/mpt-crypto` (GitHub main, vendored locally), `@noble/curves/secp256k1` (already a transitive dep), vanilla JS + HTML + CSS.

**Spec:** `docs/superpowers/specs/2026-09-04-confidential-transfers-key-management-design.md`

## Global Constraints

- No test framework exists — verification steps are manual: `npm run build` (no errors) + load unpacked extension in Chrome dev tools + interact with the popup.
- All popup UI follows the existing pattern: `showView('view-name')`, `$('element-id')`, `showAlert()`, `hideAlert()`, `togglePasswordVisibility()`.
- `popup.js` is a single file (8473 lines). Add new functions in a clearly labelled section near the bottom, before the DOMContentLoaded or last init calls.
- `saveVault()` / `loadAndDecryptVault()` / `restoreFromSession()` / `lockWallet()` are the four vault lifecycle functions — all four must be updated in Task 2.
- Hex strings stored in `state.elgamalKeys` use **uppercase, no `0x` prefix**, matching the mpt-crypto convention.
- The `devSettings` object is loaded from `chrome.storage.local` via `loadDevSettings()` and persisted via `saveDevSettings()`. Adding a new flag follows the identical pattern used by `multisignEnabled`.
- Never commit secrets. `vendor/mpt-crypto/` contains only built artefacts (no secret keys).

In the CONFIDENTIAL TRANSFERS section:
```js
async function generateElGamalKey() {
  const addr = state.activeAccount;
  if (!addr) return;

  // Generate a random valid secp256k1 private key (retry on the astronomically
  // unlikely invalid scalar — keeps [1, n-1] invariant without a library throw).
  let privKeyBytes;
  do {
    privKeyBytes = crypto.getRandomValues(new Uint8Array(32));
  } while (!secp256k1.utils.isValidPrivateKey(privKeyBytes));

  const pubKeyBytes = secp256k1.getPublicKey(privKeyBytes, true); // 33-byte compressed point

  state.elgamalKeys[addr] = {
    pubKey:  _bytesToUpperHex(pubKeyBytes),
    privKey: _bytesToUpperHex(privKeyBytes),
  };

  // Wipe the local buffer immediately — state.elgamalKeys[addr].privKey is the
  // only in-memory copy; privKeyBytes is now zeroed and will be GC'd.
  privKeyBytes.fill(0);

  await saveVault();
  renderConfidentialKeyView();
}
```

- [ ] **Step 2: Implement `confirmRevealElGamalPrivKey()`**

```js
async function confirmRevealElGamalPrivKey() {
  hideAlert('ct-reveal-error');
  const addr = state.activeAccount;
  if (!addr) return;

  const password = $('ct-reveal-password').value;
  if (!password) { showAlert('ct-reveal-error', 'Enter your password.'); return; }

  // Always re-verify against the vault — same security posture as export-key.
  try {
    const { vault } = await chrome.storage.local.get('vault');
    await decryptVault(password, vault);
  } catch {
    showAlert('ct-reveal-error', 'Incorrect password.');
    return;
  }

  const keyPair = state.elgamalKeys[addr];
  if (!keyPair) return; // shouldn't happen; guard against state race

  // Show the private key
  $('ct-reveal-controls').classList.add('hidden');
  $('ct-privkey-value').textContent = keyPair.privKey;
  $('ct-privkey-revealed').classList.remove('hidden');

  // 60-second auto-hide countdown
  let secs = 60;
  $('ct-hide-timer').textContent = `Key hidden in ${secs}s`;
  if (_ctHideTimer) clearInterval(_ctHideTimer);
  _ctHideTimer = setInterval(() => {
    secs--;
    if (secs <= 0) {
      clearInterval(_ctHideTimer);
      _ctHideTimer = null;
      $('ct-privkey-value').textContent = '';
      $('ct-privkey-revealed').classList.add('hidden');
      $('ct-hide-timer').textContent = '';
      $('ct-reveal-controls').classList.remove('hidden');
      $('ct-reveal-password').value = '';
    } else {
      $('ct-hide-timer').textContent = `Key hidden in ${secs}s`;
    }
  }, 1000);
}
```
